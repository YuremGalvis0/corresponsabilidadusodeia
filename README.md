# Portafolio de Sensibilización Ética de la IA

Este proyecto es un portafolio web desarrollado para docentes y padres de familia, con el objetivo de facilitar recursos académicos sobre el uso ético de la inteligencia artificial (IA) en entornos escolares.

## Público Objetivo
- Padres de familia (acudientes)

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript (ES6)
- Mermaid.js para diagramas

## Diseño
- Paleta de colores neutros, azules y grises
- Navegación intuitiva
- Recursos visuales llamativos: imágenes simples, textos cortos, diagramas y mapas conceptuales

## Estructura del Proyecto
- `index.html`: Página principal con secciones de introducción, recursos, actividades y contacto
- `styles.css`: Estilos CSS para diseño responsivo y visual
- `script.js`: JavaScript para interactividad (mostrar/ocultar respuestas, navegación suave)
- `assets/`: Carpeta para recursos visuales (imágenes, SVG)

## Cómo Ejecutar
1. Abre `index.html` en un navegador web.
2. Navega por las secciones usando el menú superior.

## Contenido
- **Introducción**: Explicación básica de la importancia de la ética en IA.
- **Recursos**: Mapa conceptual interactivo sobre pilares de la ética en IA.
- **Actividades**: Actividades prácticas para realizar en familia, con sugerencias ocultas que se revelan al hacer clic.
- **Contacto**: Información para contactar al docente.

Este portafolio promueve la sensibilización y el aprendizaje colaborativo entre padres e hijos sobre el uso responsable de la IA.
